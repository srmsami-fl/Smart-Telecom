2. নাম, ফোন, জেলা, শহর/উপজেলা, ডাকঘর, গ্রাম ও পূর্ণ ঠিকানা দিয়ে ফর্ম পূরণ করুন।

4. আমরা কল করে অর্ডার কনফার্ম করব।
5. পার্সেল হাতে পেয়ে দেখে-বুঝে ক্যাশে টাকা দিন।

## শর্তাবলি ও নীতিমালা (সংক্ষেপে)

পূর্ণ সংস্করণ ওয়েবসাইটের `terms.html` পেজে আছে।

- **অর্ডার:** ফর্ম জমা মানে ক্রয়ের অনুরোধ; ফোনে কনফার্মেশনের পরই অর্ডার চূড়ান্ত।
- **মূল্য ও স্টক:** বাজারদর অনুযায়ী পরিবর্তনশীল; চূড়ান্ত দাম কনফার্মেশন কলে জানানো হয়।
- **পেমেন্ট:** ক্যাশ অন ডেলিভারি বা বিকাশ। ভুল TrxID বা যাচাই না হওয়া পেমেন্টের অর্ডার প্রক্রিয়া হয় না।
- **ডেলিভারি:** কুরিয়ারে সারা দেশে; চার্জ এলাকাভেদে, কনফার্মেশন কলে জানানো হয়।
- **রিটার্ন:** ভুল/ক্ষতিগ্রস্ত/ডেফেক্টিভ পণ্য ডেলিভারির ৩ দিনের মধ্যে জানাতে হবে; পণ্য অব্যবহৃত ও বক্সসহ থাকতে হবে। ব্যবহারকারীর কারণে ক্ষতি রিটার্নযোগ্য নয়।
- **ওয়ারেন্টি:** ব্র্যান্ড/সরবরাহকারীর নীতি অনুযায়ী।
- **গোপনীয়তা:** ক্রেতার তথ্য শুধু অর্ডার ও ডেলিভারির কাজে ব্যবহৃত হয়; বিক্রি বা অন্যত্র শেয়ার করা হয় না।

## ওয়েবসাইট কাস্টমাইজ করার গাইড (Owner guide)

| কী বদলাবেন | কোথায় |
|---|---|
| ফোন, ইমেইল, ঠিকানা, Formspree, ফেসবুক/টিকটক, বিকাশ নম্বর | `js/products.js` → `SITE` |
| টিম মেম্বার, ছবি, বায়ো | `js/products.js` → `TEAM` (ছবি `assets/team/`-এ রাখুন) |
| পণ্য যোগ/বদল/মুছা (টাইটেল, দাম, বর্ণনা, ফিচার, স্পেক, ছবি) | `js/products.js` → `P(...)` লাইন |
| পণ্যের ছবি | `assets/products/` ফোল্ডারে রেখে `P(...)`-এ পথ দিন |
| রং | `css/style.css` → `:root` |

**দাম `0` দিলে** ওয়েবসাইটে “কল করে দাম জানুন” দেখাবে।

### পণ্যের শেয়ার লিংক
প্রতিটি পণ্যের জন্য নিজে নিজেই একটি লিংক তৈরি হয় (যেমন `product.html?p=itel-itel-a200-plus`)।
কার্ড বা পণ্যের পেজের 🔗 বোতামে ক্লিক করলে লিংক কপি হয় (মোবাইলে শেয়ার মেনু খোলে); পণ্যের পেজ থেকে সরাসরি WhatsApp/Facebook-এও শেয়ার করা যায়।
> লিংক ঠিকমতো কাজ করতে `SITE.url`-এ আপনার GitHub Pages লিংক বসান।

### GitHub Pages-এ লাইভ করা
1. সব ফাইল (ফোল্ডারসহ) একটি রিপোজিটরিতে আপলোড করুন।
2. **Settings → Pages → Branch: main / root → Save**।
3. `SITE.url`, `robots.txt` ও `sitemap.xml`-এ `YOUR-USERNAME.github.io/YOUR-REPO` বদলে আসল লিংক দিন।
4. Google Search Console-এ সাইট যোগ করে `sitemap.xml` জমা দিন।

### অর্ডার ফর্ম (Formspree)
অর্ডার ও যোগাযোগ ফর্ম `SITE.formspree` লিংকে যায় এবং Formspree-তে নিবন্ধিত ইমেইলে নোটিফিকেশন আসে। প্রথমবার একটি টেস্ট অর্ডার দিয়ে ইমেইল ও Formspree ড্যাশবোর্ডে এন্ট্রি আসছে কি না নিশ্চিত করুন।
